# سامانه جامع مدیریت سرمایه و ریسک S1 (نسخه ۱.۳)
### System S1 - Capital & Risk Management Engine v1.3

سامانه هوشمند تحلیل روزانه، امتیازدهی ۱۰۰ امتیازی بازارهای چهارگانه (بورس ایران، طلا و مسکوکات، تتر و ارز، رمزارزها)، تخصیص بهینه صندوق‌های سرمایه‌گذاری و ارسال خودکار گزارش ۱۳ گانه به تلگرام با پردازش هوش مصنوعی Google Gemini 3.7 Flash.

---

## 🚀 ویژگی‌های کلیدی

- **داشبورد زنده واکنش‌گرا**: نمایش وضعیت ترافیک نوری، امتیازات تفکیکی و ۴۱ متغیر بازار
- **سیستم مدیریت ریسک و وضعیت اضطراری (SRI)**: ماتریس ۵ گانه پایش ریسک‌های سیستماتیک
- **پورتفوی فرضی ۱ میلیارد تومانی (Paper Portfolio)**: ثبت معاملات، کارمزدها و پایش سقف دراودان ۱۵٪
- **ارزیابی دو مرحله‌ای ابزارهای طلا**: اولویت‌دهی صندوق شمش عیار به عنوان ابزار پایه ۸۰٪
- **گزارش رسمی ۱۳ گانه (ماده ۱۲ منشور S1)**: استخراج خودکار و ارسال روزانه به کانال تلگرام
- **استقرار خودکار روی GitHub Pages**: استقرار Static SPA بدون نیاز به سرور واسط
- **اکشن خودکار GitHub Actions (Cron Job)**: اجرای خودکار گزارش‌گیری ساعت ۱۷:۰۰ و ارسال تلگرامی

---

## 🔑 تنظیم کلیدهای امنیتی (GitHub Repository Secrets)

برای فعال‌سازی ارسال خودکار تلگرام و تحلیل هوش مصنوعی، وارد مسیر زیر در گیت‌هاب شوید:
`Settings > Secrets and variables > Actions > New repository secret`

و متغیرهای زیر را ثبت کنید:

| نام متغیر (Secret Name) | توضیحات |
| :--- | :--- |
| `GEMINI_API_KEY` | کلید API گوگل جمنای جهت نگارش تحلیل و خلاصه مدیریتی ۵ بندی |
| `TELEGRAM_BOT_TOKEN` | توکن ربات تلگرام دریافتی از `@BotFather` |
| `TELEGRAM_CHAT_ID` | شناسه کانال یا گروه مقصد (مانند `@System_S1_Channel` یا عددی مانند `-1001234567890`) |

## ⚙️ راه‌اندازی و اجرای محلی (Local Development)

```bash
# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه محلی
npm run dev

# ساخت نسخه نهایی
npm run build

# تست ارسال گزارش به تلگرام (نیازمند تنظیم متغیرها در env.)
npm run send-report
```

---

## 🌐 استقرار روی GitHub Pages

۱. در مخزن گیت‌هاب به مسیر **Settings > Pages** بروید.
۲. در بخش **Build and deployment > Source** گزینه **GitHub Actions** را انتخاب کنید.
۳. با اولین `git push` به شاخه `main`، اکشن فعال شده و سایت شما در آدرس `https://<username>.github.io/<repo-name>/` مستقر خواهد شد.

---

## 🤖 زمان‌بندی اکشن خودکار (GitHub Actions Cron)

فایل `.github/workflows/deploy-and-report.yml` به گونه‌ای تنظیم شده که:
- به صورت روزانه رأس ساعت **۱۷:۰۰ به وقت تهران** (۱۳:۳۰ UTC) گزارش بازار را تحلیل و به کانال تلگرام ارسال کند.
- از طریق تب **Actions > Deploy S1 Dashboard & Send Telegram Report > Run workflow** امکان اجرای دستی فوری گزارش نیز فراهم است.
